# ملفات السيرة الذاتية — محمد البخيتي

سيرة ذاتية جاهزة للتقديم على وظيفة **موظف مكتب خدمات عامة — غرب الرياض**.

## التصميم

السيرة مُصمَّمة بقالب **«احترافي نظيف»** (قالب `pro` في تطبيق سيرتي):
عمود واحد، مساحات بيضاء، خطوط نظيفة، عناوين ملوّنة بشريط دقيق،
نقاط مستوى بسيطة — **بدون بطاقات أو أشرطة جانبية أو تكدّس**.

## الملفات

| الملف | الاستخدام |
|---|---|
| `cv-general-services.pdf` | **النسخة الرسمية للإرسال** على الواتساب أو البريد. صفحة واحدة A4، جاهزة للطباعة، روابط قابلة للنقر (اتصال/واتساب/بريد/لينكدإن/موقع). |
| `cv-general-services.docx` | نسخة **Word** قابلة للتعديل — استخدمها لو طلبوا ملف Word أو للتقديم عبر بوابات التوظيف. |
| `cv-general-services.html` | نسخة تفاعلية مستقلة: افتحها في المتصفح (تعمل بدون إنترنت — خط Cairo مدمج)، اضغط «تفعيل التعديل» واكتب التعديلات مباشرة، ثم «طباعة / حفظ PDF». |
| `رسالة-التقديم.md` | **رسالة الواتساب + البريد + فقرة توضيح موضوع المساحة + أسئلة المقابلة**. تُرسل منفصلة عن السيرة ولا يُكتب أي منها داخل السيرة. |

## رابط واحد لكل شيء

الرقم `‎+966 56 674 3293` موضوع كرابط **اتصال مباشر** (`tel:`)، وبجانبه رابط **واتساب** (`wa.me/966566743293`)
يفتح المحادثة فورًا، إضافة إلى البريد ولينكدإن والموقع الشخصي — كلها قابلة للنقر في PDF وWord وHTML.

> ملاحظة: على الجوال يفتح رابط الواتساب التطبيق مباشرة. على الكمبيوتر يفتح WhatsApp Web.

## ما يجب تعبئته يدويًا (3 حقائق فقط)

1. **اسم الجهة التعليمية** و**التخصص** في قسم «المؤهل العلمي».
2. **اسم المكتب/المكتبة** في الخبرة — إن رغبت بذكره (النسخة الحالية تكتب «مكتبة ومركز خدمات» بدون اسم).
3. **الدورات** — احذف ما لم تحصل عليه فعلًا.

كل بقية البيانات (الاسم، الجوال، البريد، العمر، الحالة النظامية، سنوات الخبرة) مأخوذة من بياناتك الحقيقية في المشروع.

## إعادة توليد الملفات

```bash
pip install fpdf2 uharfbuzz python-docx
python3 cv/build_pdf.py     # ينتج cv-general-services.pdf
python3 cv/build_docx.py    # ينتج cv-general-services.docx
python3 cv/build_html.py    # ينتج cv-general-services.html (يتطلب Node.js)
```

- الخط المستخدم هو **Cairo** والملفات موجودة داخل `cv/fonts/` (وداخل ملف HTML بصيغة base64، لذلك يعمل على أي جهاز بدون إنترنت).
- `build_html.py` يستخرج السيرة مباشرة من تطبيق سيرتي (نفس القالب والبيانات المستخدمة في المحرر).

## موضوع «الخلفية المساحية» — مهم

الموقع الشخصي فيه أعمال هندسية/مساحية، لذلك **لا تخفِ ذلك ولا تشرحه داخل السيرة**.
الشرح كامل وجاهز في `رسالة-التقديم.md` (فقرة رقم 3): بصراحة عن أن مجال المساحة موسمي، وأنك اخترت
هذا المسار عن قناعة بحثًا عن استقرار، مع عرض تجربة عملية أسبوعين لإثبات الالتزام.

## نصائح إرسال سريعة

- أرسل الـ **PDF أولاً** ثم الرسالة، أو رسالة قصيرة جدًا مع الملف.
- لا تُرسل ملف Word إلا إذا طلبوه.
- سمِّ الملف: `محمد-البخيتي-سيرة-ذاتية.pdf` قبل الإرسال.
- عند المقابلة: الملفات المطبوعة + الهوية + الشهادات، والحضور قبل الموعد بعشر دقائق.
