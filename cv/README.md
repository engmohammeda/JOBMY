# ملفات السيرة الذاتية — محمد البخيتي

سيرة ذاتية جاهزة للتقديم على وظيفة **موظف مكتب خدمات عامة — غرب الرياض**.

| الملف | الاستخدام |
|---|---|
| `cv-general-services.pdf` | **النسخة الرسمية للإرسال** على الواتساب أو البريد. صفحة واحدة A4، جاهزة للطباعة. |
| `cv-general-services.docx` | نسخة **Word** قابلة للتعديل — استخدمها لو طلبوا ملف Word أو للتقديم عبر بوابات التوظيف (ATS). |
| `cv-general-services.html` | نسخة تفاعلية: افتحها في المتصفح، اضغط «تفعيل التعديل» واكتب التعديلات مباشرة، ثم «طباعة / حفظ PDF». |
| `رسالة-التقديم.md` | رسالة الواتساب + البريد الإلكتروني + أسئلة المقابلة المتوقعة وإجاباتها. |

## ما يجب تعبئته يدويًا (3 حقائق فقط)

1. **اسم الجهة التعليمية** و**التخصص** في قسم «المؤهل العلمي».
2. **اسم المكتب/المكتبة** في الخبرة — إن رغبت بذكره (النسخة الحالية تكتب «مكتبة ومركز خدمات» بدون اسم).
3. **الدورات** — احذف ما لم تحصل عليه فعلًا.

كل بقية البيانات (الاسم، الجوال، البريد، العمر، الحالة النظامية، سنوات الخبرة) مأخوذة من بياناتك الحقيقية في المشروع.

## إعادة توليد الملفات

```bash
python3 cv/build_pdf.py     # ينتج cv-general-services.pdf
python3 cv/build_docx.py    # ينتج cv-general-services.docx
```

المتطلبات: `pip install fpdf2 pypdfium2 python-docx` — الخط المستخدم Cairo ومضمّن داخل مجلد `cv/fonts`
(وداخل ملف HTML بصيغة base64، لذلك يعمل على أي جهاز بدون إنترنت).

## نصائح إرسال سريعة

- أرسل الـ **PDF أولاً** ثم الرسالة، أو رسالة قصيرة جدًا مع الملف.
- لا تُرسل ملف Word إلا إذا طلبوه.
- سمِّ الملف: `محمد-البخيتي-سيرة-ذاتية.pdf` قبل الإرسال.
- عند المقابلة: الملفات المطبوعة + الهوية + الشهادات، والحضور قبل الموعد بعشر دقائق.
