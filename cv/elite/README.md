# قالب «النخبة» — Elite

قالب السيرة الأرقى في «سيرتي»، ومعه خط إنتاج كامل ينتج **ثلاث صيغ من مصدر واحد**.

## لماذا هذا القالب؟
| القرار التصميمي | السبب |
|---|---|
| عمود واحد (لا أشرطة جانبية) | يُقرأ بمسار نظر واحد، ويبقى نظيفًا عند الطباعة وعند تصوير الشاشة |
| عناوين أقسام مرقّمة (01، 02، …) | يُسهّل الإشارة إلى أي قسم في المقابلة («كما في القسم الثالث») |
| خطوط شعرية رقيقة بدل صناديق ملوّنة | يفصل دون أن يزدحم؛ الألوان محصورة في لون أساسي واحد ولمسة ذهبية |
| شريط جانبي بعرض 2.3 مم | هوية بصرية خفيفة تُبقي الورقة متماسكة دون استهلاك مساحة |
| مساحات بيضاء محسوبة (لا مصادفة) | فراغ 11–16 مم، تباعد أسطر 1.62، وفواصل أقسام 3.9 مم — كلها مضبوطة لتمتلئ A4 دون تكدّس |
| خط IBM Plex Sans Arabic | خط سعودي/عالمي واضح على الشاشة والورق، مضمّن داخل الملف فلا يعتمد على جهاز المُرسل |

## الملفات
```
data.json        المصدر الوحيد للبيانات (عدّله ثم أعد التوليد)
cv.css           تصميم الورقة المستقلة (الشاشة + الطباعة A4)
template.css     نفس التصميم كقالب داخل التطبيق (.tpl-elite)
../build_elite.py  المولّد: HTML + PDF + Word + حقن الخطوط في التطبيق
```

## التوليد
```bash
python3 cv/build_elite.py           # كل شيء
python3 cv/build_elite.py --embed   # تحديث الخطوط والقالب داخل index.html فقط
python3 cv/build_elite.py --pdf     # PDF (Playwright/Chromium → A4 حقيقي)
python3 cv/build_elite.py --docx    # Word (RTL صحيح، اتجاه أرقام مضبوط)
python3 cv/preview_elite.py         # معاينة + قياس ارتفاع المحتوى بالمليمتر
```

## قواعد التحرير
1. عدّل **`data.json` فقط** — لا تحرّر HTML أو CSS لكل تغيير نصي.
2. أبقِ الملخص بين **400–460 حرفًا** ليبقى في صفحة A4 واحدة (المؤشر أعلى المعاينة يخبرك فورًا).
3. النقاط في `bullets`: فعل + ماذا + لماذا يهم (تجنّب الصفات العامة بلا دليل).
4. لا تُضف صورة شخصية لهذا القالب؛ نظافته في غيابها.
